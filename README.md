\# Book \& Quotes App



Responsive CRUD web application built with \*\*Angular 20\*\* and \*\*.NET 9 ASP.NET Core Web API\*\*.



This project is developed as part of a technical test for an internship (LIA) and demonstrates full-stack development, REST API design, authentication, CRUD operations and responsive UI development.



\## Tech Stack



\### Frontend



\- Angular 20

\- TypeScript

\- SCSS

\- Bootstrap

\- Font Awesome



\### Backend



\- .NET 9

\- C#

\- ASP.NET Core Web API

\- Entity Framework Core

\- SQL Server

\- JWT Authentication

Running the Backend



Navigate to the API project:



cd BookQuotes.Api



Run the application:



dotnet run



The API will start on the local development URL shown in the terminal.



Running the Frontend



Navigate to the Angular application:



cd frontend/book-quotes-ui



Install dependencies:



npm install



Start the development server:



ng serve



The application is available at:



http://localhost:4200
